# OmniFoto
OmniFoto to lokalna przeglądarka zdjęć i wyszukiwarka tapet — nowoczesny, prywatny i przejrzysty program działający wyłącznie na komputerze użytkownika. Łączy wygodę znaną z serwisów z tapetami (kafelki, lista, podgląd, ulubione, pokaz slajdów) z bezpieczeństwem bez śledzenia, bez reklam, bez telemetrii, bez zapisywania historii w trybie prywatnym.
